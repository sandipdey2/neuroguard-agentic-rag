## How the new pieces fit one run

1. **Planner** calls MCP `episode_recall` (similar de-identified past episodes + learned hints) and writes a structured plan.
2. **Orchestrator** executes the plan step by step (LLM choice, code-enforced eligibility); every choice goes to the decision log.
3. **Evidence Researcher** runs a ReAct loop over `search_guidelines` (hybrid sparse + dense vectors) and `graph_traverse` (multi-hop graph RAG). Code measures which required topics (risk factors present + warning signs) are covered by cited excerpts; if any are missing it re-retrieves once with a reformulation instruction (agentic RAG).
4. **Clinical Writer** receives evidence packed to a token budget (tiktoken), learned hints, then critiques its own draft (deterministic checks + an LLM critique whose quotes must exist in the draft and show the rule's surface form) and revises once.
5. **Safety Reviewer** (12-check verifier + quote-confirmed red team) -> **finalize gate** -> **confidence gate** (refuse < 0.4, clinician review < 0.7).
6. The harness writes one de-identified **episode** (MCP `episode_write`, harness-only), prices every LLM call, exports spans as OTLP-JSON and signs a receipt that includes the decision-log hash, cost and confidence. A clinician's approve/reject is written back to the episode and feeds the bounded learning loop.

## Honest limits

- Dense vectors inside the MCP server are local LSA, not OpenAI embeddings, because the server deliberately holds no API key; the notebook compares both.
- The confidence score is a transparent weighted heuristic, not a calibrated probability that the report is correct.
- The learning loop changes only whitelisted hint texts and bounded retrieval boosts; it never edits code, prompts, the contract or model weights.
- Multi-modal input reads three lab fields; scanned PDFs (no text layer) are refused; it was tested on rendered images of real dataset values, not real scans.
- Batch mode is single-process concurrency for a small cohort; v2.3 adds a durable queue + workers (API / webhook / schedule), tested on one machine, not load-tested on a cluster.
- Web search is not a general search engine: it ranks the corpus' known CDC / NIH / WHO source pages and fetches them live; web text is context, never a citation. On the development box DNS answers come from a fake-IP proxy (198.18.0.0/15), which the SSRF guard accepts only when NG_FAKEIP_DNS=1 is set; Streamlit Cloud resolves normally and needs no flag.
- The shell tool is an argv allowlist sandbox (grep / wc / head / ls, no interpreter, empty env, timeout), not an OS container.
- In agentic-search mode the harness sends one 'source check' message if the LLM finished without consulting a required source class; the LLM still chooses the call. Without it gpt-4o-mini often stopped after semantic_search.
