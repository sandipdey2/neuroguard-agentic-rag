# knowledge/ - local read-only documents for agentic search

Searched by the MCP tools `search_files` and `shell` (grep / wc / head / ls only). Together with `skills/*/SKILL.md`
these are the "local files" source of the agentic-search context-engineering mode.

- `Plan.md` - the evidence research plan the Evidence Researcher follows.
- `guideline_titles.md` - titles, publishers and URLs of the 30 public-domain guideline excerpts.
- `cohort_schema.md` - schema of the read-only SQLite table `patients` used by `execute_query`.
